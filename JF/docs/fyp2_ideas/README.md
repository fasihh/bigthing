# FYP-2 idea generation (working files)

How the FYP-2 proposal (`JF/proposal/proposal.pdf`) was reached:

1. `BRIEF.md` — FYP-1 results and limitations given to every agent.
2. `trends.md` — literature scout: ~55 papers (2025–2026), trends and open gaps.
3. `inventor_crossmodal.md`, `inventor_probabilistic.md` — two independent method inventors (cross-modal /
   world-model angle and probabilistic angle). Both converged on inferring which modality is corrupted from
   cross-modal consistency.
4. `proposal_review.md` — critic: novelty audit (incl. classical fault detection), merged design
   (Cross-Examined Fusion), hypotheses, baselines, compute, pilot, risks, and scores for every idea.

Predicted numbers in these files are hypotheses, not results.
