# Technique catalogue for the short noisy-TV screen

Problem: each modality's expert outputs a Gaussian belief (mu_m, var_m). When one input is
replaced by noise or by another clip, the expert's own variance does not rise (FYP-1 finding),
so precision-weighted fusion trusts it. We look for techniques that (a) notice the bad input,
(b) stop it from dragging the prediction, (c) widen the range when they cannot fix it,
and (d) cost nothing on clean data.

Every technique is screened on the same bench (bench/), same seeds, same conditions,
with thresholds set on clean calibration data only (no corrupted data used for tuning,
except where a technique *generates its own* synthetic corruptions — marked [self-sup]).
Structured AR noise is never generated by any technique, so it is a held-out corruption.

| B1 | PoE (naive) | ours / Wu & Goodman 2018 | product of expert Gaussians |
| B2 | PoE, prior-corrected | ours (poe_pc) | divide out the M-1 extra copies of the prior |
| B3 | Mixture mean (MoE-equal) | ours | equal-weight Gaussian mixture |
| B4 | Learned gate (stacking) | ours (attention baseline) | MLP on (mu, log var) of all experts -> weights |
| O1 | Oracle drop | upper bound | drops the truly corrupted modality |
| R1 | Precision-weighted median | robust statistics / Byzantine (coordinate median) | median instead of mean |
| R2 | Huber M-estimator fusion | robust statistics (IRLS) | downweight large standardised residuals |
| R3 | Student-t product (EM) | robust Kalman filtering (Student-t KF, VB) | heavy-tailed experts, scale weights by EM |
| R4 | Trimmed PoE (drop most deviant) | Byzantine trimmed mean / Krum | drop the expert farthest from the rest |
| F1 | Chi-square innovation gating | sensor FDI / Kalman NIS test | leave-one-out residual vs chi2(1) threshold |
| F2 | Good-and-bad contamination BMA | Box & Tiao 1968; Sivia | exact posterior over 2^M inlier/outlier states |

| K1 | Split conformal on PoE | conformal prediction | rescale ranges to 90% on clean cal data |
| K2 | Mondrian conformal by suspicion bin | Mondrian CP (Vovk) | separate quantile per suspicion level |
